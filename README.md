# presentExs

Chrome extension untuk kontrol Google Slides dengan voice control, subtitle, dan toolbar mengambang.

## Fitur
- 🎙️ Voice control (Whisper lokal + Web Speech API)
- 💬 Subtitle real-time dengan kustomisasi
- 🎛️ Floating toolbar dengan auto-hide
- 📱 Remote via HP dengan QR scan
- 🔗 Kontrol Google Slides (present/next/prev)
